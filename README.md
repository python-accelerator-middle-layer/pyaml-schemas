# pyaml-schemas
JSON Schema for pyAML configuration

## Schemas

Schemas are generated by the `Update JSON schemas` workflow and published on GitHub Pages:

| Version | Built from | URL |
|---|---|---|
| `release` | Latest release of all packages | https://python-accelerator-middle-layer.github.io/pyaml-schemas/release/accelerator.schema.json |
| `main` | `main` branch of all packages | https://python-accelerator-middle-layer.github.io/pyaml-schemas/main/accelerator.schema.json |

`schemas/accelerator.schema.json` in this repository is frozen and no longer updated. It will be removed once the documentation points to the URLs above.

## Generating locally

```bash
pip install -r requirements-release.txt  # or requirements-main.txt
python scripts/generate-schemas.py --output schemas
```
